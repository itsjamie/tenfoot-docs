## Effects

An effect is a number saved with each shape. The GPU program already reads it. You name your effects when you create the renderer. An app that names none gets the exact same GPU program as before effects existed.

```ts
const r = createRenderer(canvas, { text, effects: ['grade', 'shimmer'] });
r.gl.setEffect('grade', [0.85, 0.35, 0, 0]);   // how gray, how dim
r.gl.setEffect('shimmer', [phase, 1, 0.16, 0.6]); // position, bands, brightness, slope
p.pushEffect(FX_GRADE); /* draw */ p.popEffect();
```

An effect's numbers are set once per frame. Each shape only stores which effect it wants. So a screen with gray cards mixed in with normal ones costs no extra draw calls. Text inside an effect is drawn normally, because text uses that same number for something else.

## Shaders

A shader is your own GPU program, used around one node. It costs one draw call where it starts and one where it ends. That is about the same as changing a picture. It is right for the one card that has focus. It is wrong for a grid of them.

```ts
const ring = r.gl.shader({
  id: 'app:ring',
  glsl: 'vec4 shade(vec4 base) { float t = fract(atan(v_local.y, v_local.x) * 0.159 + 0.5 - u_shader.x); return vec4(base.rgb + smoothstep(0.62, 1.0, 1.0 - abs(t - 0.5) * 2.0) * u_shader.y, base.a); }',
});
r.gl.setShader(ring, [phase, 0.5, 0, 0]);
p.pushShader(ring); /* draw the ring */ p.popShader();
```

You write `shade(vec4 base)`. It gets the color the renderer was about to draw, and returns the color to draw instead. You can use `u_shader` (your four numbers), `v_local` (where you are inside the shape, as small numbers around zero), `v_uv`, and `u_color`. If your shader does not compile, the renderer draws normally and warns once.

Keep your numbers small. On at least one 2017 TV, the GPU uses 16-bit math. Anything that keeps growing freezes once it passes 65504.

## Targets

```ts
const shot = r.gl.createTarget(0.25);       // a quarter of the screen in each direction
if (shot && r.scene.capture(shot)) r.gl.blur(shot, 4);
p.target(shot, 0, 0, 1920, 1080);           // draw it back
r.gl.releaseTarget(shot);
```

This is for the screen behind a dialog. Capture it once when the dialog opens. Blur it once. Draw it as a picture while the dialog is up. Release it when the dialog closes. It is not for redrawing to a picture every frame. That is a different feature with a different cost.
