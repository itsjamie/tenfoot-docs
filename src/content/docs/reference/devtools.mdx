## The overlay

`overlay: 'info-key'` (the default) turns it on and off with the remote's Info key, or `I` on a keyboard. `'on'` keeps it on. `'off'` leaves it out. It shows frames per second, how long frames take, draw calls, shapes drawn and skipped, GPU memory against its limit, which item has focus, and how focus got there. Your `overlayLines()` function can add lines. It only redraws when the screen does, so it never costs a frame.

## The inspector

`inspector: true` copies the scene tree into empty, nested HTML elements on top of the canvas after each frame. Each element has the node's name, box, scale, opacity, and label as `data-` attributes. So the browser's Inspect Element shows your scene tree. For development only.

## Diagnostics

`r.diagnostics()` is what a test or a remote console reads: `drawCalls()`, `stats`, `scene`, `caps`, `imagesPending()`, `images()`, `image(key)`, `focus()`, `navigation()`, `subtitles()`, `debug()`. Your app can add its own. The sample app publishes it as `window.__arena`.
