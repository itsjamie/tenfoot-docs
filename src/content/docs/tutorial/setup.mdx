A TV app is a web page with a canvas on it. The TV gives that page a screen that is 1920 by 1080 pixels. It also gives you a video layer under the page. The browser is whatever the TV came with. Everything else is up to you.

Make a folder and install the tools:

```sh
mkdir my-tv-app && cd my-tv-app
pnpm init
pnpm add tenfoot
pnpm add -D vite @vitejs/plugin-legacy typescript
```

## The page

The canvas covers the whole screen. The video sits under it. We put the video in the HTML instead of making it later, for two reasons. The caption track has to be in the HTML. And the TV's own player connects to a real video element.

Notice `preload="none"` and no `autoplay`. This keeps the TV's video decoder off while you browse. The player screen will call `play()` when it opens.

## The build

Old TVs run old browsers. None of them can load modern JavaScript modules. So the build makes one old-style (ES5) file. The `@vitejs/plugin-legacy` plugin does this. It turns your code into something a 2017 browser can run. You still write modern TypeScript. Nothing in this file is special to the library.

## Two rules for your own code

**Do not use `async`/`await` or generators.** They turn into slow code on a 2017 TV. A TV app can use plain callbacks instead.

**Do not use `fetch`.** Chromium 38 does not have it. Use `XMLHttpRequest`. `Promise` and `Map` are fine.
