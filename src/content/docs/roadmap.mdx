Three things are next. If you want to help with any of them, [open an issue](https://github.com/itsjamie/tenfoot-docs/issues).

## Testers

We are looking for people outside the project to build something with Tenfoot and tell us where it gets in the way. You do not need a TV to start. A desktop browser runs everything on this site.

## More devices

Every number on this site comes from a desktop computer so far. We are gathering numbers from real TVs and set-top boxes, starting with 2017 LG and Samsung sets. If you have one and can run a test page on it, we would like to hear from you.

## An easier API

We want Tenfoot to be easier to learn and to take less code to write. That will not change its main design: it is a zero-cost abstraction. A helper should draw the same shapes, in the same draw calls, as the code you would have written by hand. If an easier way costs something on every frame, it does not go in.
